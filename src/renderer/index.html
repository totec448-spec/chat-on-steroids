    Setup
    Connect your workspace to ChatGPT.
    
              
    
                
                
                
                
                
                
                
                
                
                
              
    
            
    
            
    
              
    
                Follow these six steps once. The pictures show where to click. Start with Core;
                desktop control is optional.
              
    
              
            
    
            
    
              
              
            
    

            
      
              
              
    1. 
                
      
                  
                
      
                
      
                  
      Pick a folder to share
      
                  
      
                    Choose the folder you want ChatGPT to work in. You can add more folders later.
                  
      
                  
      
                    
                    
                    None yet
                  
      
                
      
              
      2. 

              
              
    2. 
                
      
                  
                
      
                
      
                  
      Create a tunnel
      
                  
        
                    
      1. Open Tunnels and click “Create tunnel” at the top right of the page. Enter a name and description.
        2. 
                    
      2. At the bottom, select your workspace under ChatGPT workspaces. Choose the same workspace you use in ChatGPT. You can search by name or workspace ID.
        3. 
                    
      3. Keep your existing organization selected. Selecting an organization alone does not make the tunnel appear in ChatGPT.
        4. 
                    
      4. Click Create, copy the new Tunnel ID and paste it below.
        5. 
                  
      
                  
      
                    
                  
      
                  
      
                  
      
                    
                    
                  
      
                  
                  
      
                    Desktop control optional
                    
      
                      
                      
                      
      
                        Screen and mouse/keyboard control are a separate connector, so they need a
                        second tunnel. Create another one and paste its ID here. Leave it empty to
                        keep desktop control off in ChatGPT.
                      
      
                    
      
                  
      
                
      
              
      3. 

              
              
    3. 
                
      
                  
                
      
                
      
                  
      Create an API key
      
                  
        
                    
      1. Open API keys and click “Create new secret key” at the top right of the page.
        2. 
                    
      2. Leave Owned by set to You. Select your project, for example Default project. A name is optional. An expiration date is required.
        3. 
                    
      3. Under Permissions, choose Restricted. Scroll down to Tunnels and enable Read and Use. Leave everything else at None.
        4. 
                    
      4. Create the key, copy it and paste it below. You can only copy the secret once.
        5. 
                  
      
                  
      
                    
                  
      
                  
      
                  
      
                    
                    
                    
      
                    
      
                      
                    
      
                  
      
                
      
              
      4. 

              
              
    4. 
                
      
                  
                
      
                
      
                  
      Start the tunnel
      
                  
      Click Connect and wait for Connected. The tunnel must be running before you can add the plugin in ChatGPT.
      
                  
      
                    Leave it running while you use the connector. It stays available when you close
                    the window.
                  
      
                  
      
                    
                    
                  
      
                
      
              
      5. 

              
              
    5. 
                
      
                  
                
      
                
      
                  
      Add it in ChatGPT
      
                  
      A · Developer mode (older ChatGPT versions only)
      
                  
      If your ChatGPT settings still show Developer mode, turn it on under Settings → Security and login. Newer versions of ChatGPT no longer have this switch; then skip this step.
      
                  
      
                  
      B · Create the Core plugin
      
                  
      
                    
                  
      
                  
        
                    
      1. Open the ChatGPT Plugins page using the button above. At the top right, click Add and choose Create MCP App (older versions show a + instead) to open New Plugin.
        2. 
                    
      2. Copy the name and description from the Core card below. Keep the name exactly as shown: CoS recognizes its tool calls by this name, and a renamed plugin's calls are not linked to your chats.
        3. 
                    
      3. 
                    
      4. Under Authentication, choose No authentication. Do not paste your API key here.
        5. 
                    
      5. Read and accept the notice, then click Create. Keep the tunnel running while ChatGPT connects.
        6. 
                  
      
                  
      
                  
                  
      
                  
      
                    Before you start: choose “Allow all actions”
                    
      In ChatGPT, open Settings → Plugins, select this plugin, and set its action permissions to Allow all actions. Repeat for the Desktop plugin if you added it.
      
                    
      This lets ChatGPT use the plugin without asking for each action. Otherwise, approval prompts can pause Goal, Loop and agent tasks. Your folder and tool permissions in this app still apply.
      
                  
      
                  
      
                    
                  
      
                
      
              
      6. 

              
              
              
    6. 
                
      
                  
                
      
                
      
                  
      Add the Chrome extension
      
                  
        
                    
      1. Open chrome://extensions.
        2. 
                    
      2. Turn on Developer mode at the top right.
        3. 
                    
      3. Click Open extension folder below and copy the folder path from the file manager’s address bar.
        4. 
                    
      4. In Chrome, click Load unpacked, paste the copied folder path and select that folder.
        5. 
                  
      
                  
      The extension pairs with this app automatically — there is no code to type.
      
                  
      
                    Required for sub-agents: the companion extension must be loaded
                    and connected in ChatGPT. Without it, Chat On Steroids cannot identify, open or
                    coordinate worker chats.

    Continuation sources
    
                
    
                  
                  
    Recovery timing details
    Recover unfinished answers, including in Goal and Loop. Reload after 2 minutes without progress (Pro: 10). If still generating, wait 1 more minute (Pro: 5), then stop and send. A final answer selects Goal or Loop instead of Continue. Undelivered tickets share reload intervals of 2, 5, 10 and 15 minutes.
    
                  
    Goal response sourceAPI is the most reliable. Offline uses completion markers and 200 prepared messages.
    
                  
    Loop response sourceLoop keeps going until you switch it off.
    
                  
    Goal, Loop and Plan modelModel for ChatGPT-generated messages and plans. Select GPT-5.6 and High below for planning.
    
                  
    Goal, Loop and Plan reasoningUsed with the ChatGPT model above; independent from API reasoning.
