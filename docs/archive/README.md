| --- | --- |

| Triage and review ledgers | `github-triage-*`, `worklog-*-pr-review`, `worklog-*-triage` |
| Worklogs | `worklog-YYYY-MM-DD-*` |
| Incident write-up | `public-history-privacy-incident-*` |
