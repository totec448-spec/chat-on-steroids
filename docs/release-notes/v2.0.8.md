## Darkex by dark tibo

## 2.0.8

- New Plugins workspace with an independent MCP connector, a reviewed catalog, custom servers and MCPB imports. Manage installation, enabled tools, credentials, updates and connection status in one place.
- Blender, Memory, Playwright, Fetch and Unity integrations, plus browser sign-in for hosted HeyGen and Recraft services. Enabled plugins restore across app restarts; failed updates preserve the previous installation.
- Desktop-launched macOS/Linux apps find runtimes in standard Homebrew, Node and user uv installation locations while preserving the user's configured PATH precedence.
- Full third-party notices are available before installation. Catalog license references preserve exact upstream terms, and CI checks dependency notices and catalog hashes.
- Resizable and collapsible sidebar, a compact View menu and Windows title bar, native composer context menus, clearer extension-update actions and faster conversation-list loading.
- Chat transcripts display safe Markdown links, tables and uploaded-file references. Plugin results show readable content and bounded image previews while preserving complete recorded responses.
- Image attachments sit in a separate row above the text bubble, consistently while sending and after delivery.
- Model pickers retain observed account choices and selected reasoning across loads. Usage displays distinguish model families and retain the provenance of estimates.
- Planning sends the complete request and plan together, with later stages available as checkpoints. Queue presentation avoids duplicate plan previews, and timeline paging preserves the reading position in both directions.
- Browser handoffs reuse eligible documents and retain one opening owner across acknowledgements and navigation. Waiting chats, sleeping workers, pending inputs and drafts remain protected; cancelled or failed helpers retire only with matching proof.
- Queued input follows the durable session through Compact & Resume. Companion setup, model discovery and browser recovery report their current state more clearly.

**Reload the matching companion extension after updating the app.** This update includes all current application and extension changes; private recordings, screenshots and local worklogs are excluded.

The native source download accompanies the installers and is covered by the release checksums.
Installed notices link to it and explain the LGPL/MPL components and library replacement.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

Core and the workspace support Windows, macOS and Linux. Desktop screen/input control is available on Windows and optionally macOS with Screen Recording and Accessibility permissions. External plugins run with their own OS or service permissions and do not inherit approved-folder restrictions. Hosted-service terms and account limits apply. This project remains beta.
