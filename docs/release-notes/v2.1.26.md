## 2.1.26 New chats and long runs stay on track

This update is about messages that got lost and long Goal, Loop and worker runs that stalled or reloaded for no reason. A new chat's first answer keeps its turn when ChatGPT is slow, sending into an existing chat works again on ChatGPT's current page, messages you send while ChatGPT is working no longer look like a stall, and Goal's helper chat works reliably again.

### Fixed

- **A new chat's first answer keeps its turn, Copy and Export.** When ChatGPT was slow, it redrew a new chat before CoS had read your question once. The send was never confirmed ("Stopped waiting for delivery confirmation"), the answer appeared above the question, had no Copy or Export, and its tool calls and progress weren't recorded with it. CoS now confirms the send from ChatGPT's own request and opens the turn from it.
- **Sending into an existing chat works on ChatGPT's current page.** ChatGPT's page grew deeper than CoS looked, so it couldn't read the model picker, and sends failed with "Requested model or reasoning could not be confirmed".
- **An already selected model is confirmed directly.** When ChatGPT already had the requested model and effort selected, CoS still clicked through other model versions, and that could fail.
- **Messages you send while ChatGPT works no longer cause reloads.** A message sent during a running answer joins that answer. CoS didn't count the work that followed as progress, decided the chat had stalled and reloaded it in the middle of the work.
- **No more Continue loop on a finished answer.** When ChatGPT refused an automatic Continue because the answer was already complete, CoS kept trying again. It now ends that Continue.
- **Answers are kept when ChatGPT hides their question.** ChatGPT sometimes draws an exchange without your message. CoS then lost track of the question or the answer, and the chat looked stuck.
- **Compact & resume continues after an answer that broke off.** When ChatGPT broke off the answer with an error while a compaction was waiting, CoS now reloads the chat and carries on instead of waiting for nothing.
- **Goal's helper chat works reliably again.** Goal writes its next step in a temporary ChatGPT chat. CoS missed the helper's answer when ChatGPT removed the helper's question from the page, and after a send that timed out, Goal couldn't ask again.
- **Woken workers get their messages.** A worker that was woken up again under a new run could miss messages addressed to its earlier run.
- **Goal's helper no longer runs tools.** The temporary chat Goal uses to write its next step could call this app's tools itself, and an answer after such a call was never picked up. The helper is now told not to use tools, and its answer is taken either way.
- **Workers start reliably in bursts.** When several workers opened at once, a new tab could give up fetching its instruction after two seconds and stay on an empty page. It now keeps trying while the app waits.
- **Commands keep running across turns.** Input to a command started in an earlier turn was sometimes refused because the new turn hadn't been matched to its chat yet. CoS now waits briefly for that match.
- **Automatic compaction no longer waits forever on a broken connection.** When ChatGPT showed "Connection interrupted" while its Stop button stayed visible, the chat kept saying it was still working, and a due compaction never started. After a minute the app now reloads the chat and compacts.
- **Documents ChatGPT is still writing show properly.** A long answer written as a document showed as raw `:::writing` text until it was complete, and stayed raw when you stopped it.
- **Setup keeps the browser step done.** About a minute after start, Setup showed the browser as missing whenever no ChatGPT tab was open, although it was connected.
- **Each round of work ends with its own summary in the timeline.** A recap no longer lands in the wrong round, and steps read late (after a reload) keep their place.
- **No more "Reload failed" while ChatGPT is answering.** When ChatGPT resumed an interrupted answer by itself, the chat row kept flipping between "Trying to reload" and "Reload failed" although nothing had failed. It now says recovery waits until the answer finishes.

### Improved

- **See the first answer's progress in a new chat.** While ChatGPT works on the first answer of a new chat, the app now shows what the model writes between its steps, instead of only the tool calls until the end.
- **Choose whether your messages mention Chat On Steroids Core.** A new setting, on by default, adds the mention that makes ChatGPT use the app in every chat. Turn it off if ChatGPT starts simple questions with an unneeded tool call. Workers, Goal, Loop and Continue always keep it.
- **The window remembers its size and place.** The app opens where you left it, at the same size, and maximized if you left it maximized. If that screen is gone, it opens on the main screen.
- **Clearer Goal and Loop timing.** With Session finish, the choice of when Goal or Loop continues now reads "Session Finish only" or "Also after the turn", with a tooltip explaining each.
- **A simpler connection menu.** The connection menu shows the status and Connect or Disconnect. Detailed diagnostics stay in the browser extension's popup.
- **Choose a default model for new chats.** Settings › ChatGPT models has a default model and reasoning for new chats. "Automatic" keeps today's behavior, a chat you continue keeps its own model, and workers and helpers keep their own defaults.
- **Search all OpenRouter models.** Goal's OpenRouter model list has a search field that searches the whole catalogue, not just the loaded page.
- **Follow new output.** A new setting, on by default: the app and the ChatGPT page stay at the end of the chat while answers grow. Scrolling up pauses it.
- **Russian and Vietnamese.** The app is now available in Russian and Vietnamese.
- **The extension speaks the app's language.** The popup and the controls on ChatGPT follow the language you chose in the app instead of Chrome's, and they are now also available in Korean and Portuguese.
- **Extension settings survive a reinstall.** Timestamps and Overwrite come back after the extension is reinstalled from a new folder.
- **Small windows.** Headers, settings rows, buttons and cards stay inside the window down to the smallest size, in every language. The language flags on Setup no longer cover the title.
- **Numbers in your language.** Usage totals and amounts follow the app language, and the Activity log no longer fills with identical lines while Usage is open.
- **Clearer settings.** Session finish now says it works with Pro models and needs a plugin refresh. Settings whose switch is off are dimmed instead of looking editable.
- **Worker health in the sub-agent overview.** Each worker shows a short health label next to its state.
- **Installed Skill revisions.** The Skills library shows which GitHub commit of a Skill is installed.
- **Optional cleanup of sleeping workers.** A new setting, off by default, ends the background processes of sleeping workers. Their chats stay reusable.
- **ChatGPT knows the current permissions.** CoS tells ChatGPT which local permissions are active right now, so it tries fewer tools that would be refused.
- **Canary builds.** Every change to main is also published as a rolling "canary" test build. Canary builds have no release notes and no support, and we don't accept reports or pull requests based on them.
