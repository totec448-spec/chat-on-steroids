> **macOS:** the builds are publisher-unsigned and unnotarized, so Gatekeeper may warn; verify the checksum first. They require macOS 13 Ventura or newer.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

Core tools and the desktop workspace target Windows, macOS and Linux. Desktop screen/input control is available on Windows and optionally macOS, where Screen Recording and Accessibility permissions are required; it is unavailable on Linux. Notification delivery/actions depend on OS support. Cold background Chrome focus and notification actions have not been verified on every supported desktop environment. macOS ad-hoc sealing provides bundle integrity, not publisher trust or notarization.

Windows and Linux AppImage can install verified updates. macOS and Linux DEB direct you to a manual download. Source tests and package CI do not replace testing on your own desktop and browser profile.

Beta despite the version number. Behaviour may still change between releases.
