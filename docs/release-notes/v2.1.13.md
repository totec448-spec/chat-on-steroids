## 2.1.13: Skills and reliability

Bring your own text skills. Open **+ → Skills** to import Markdown/text instructions and choose a skill from the list. Type **/** in the composer to autocomplete installed skills, or use `/prompt <id>`.

Selected skills are inserted below the main prompt and above AGENTS.md and your task. The existing 96,000-character limit keeps skills and user text complete, using less AGENTS.md when space is tight. Models can read or install skills through the existing Core tools in `/skills`. The library starts empty; skills do not add tools or run scripts automatically.

This release includes the **2.1.12 ChatGPT model-picker fix** for main chats and workers, plus local fixes for request attribution, repeated transport errors, answer completion, Goal/Loop recovery, worker revival and clearer tool/plugin failures. Contributor credit remains in `CONTRIBUTORS.md`.

The end of Setup and a one-time reminder on the first model-discovery opening explain ChatGPT's tool approval prompts. Check the ChatGPT window for **Allow once / Always allow / Deny** when Goal, Loop or an agent appears to be waiting. Acknowledging the CoS reminder does not approve a tool action.

Image follow-ups keep their place in the transcript even when preview storage is full, with retained previews and separate delivery receipts. New project chats explicitly name their primary working folder, including projects without AGENTS.md.

Setup now walks through checking Core's Actions list. Health checks distinguish tunnel connectivity, actual catalog responses, and tool requests. Stale calls reaching the wrong connector get specific guidance instead of a misleading generic disabled-plugin message. Native-source packaging retries transient download failures while preserving every source checksum.

**Reload the companion extension and refresh your ChatGPT tabs after updating.** Refresh the CoS connectors when prompted. [Skills guide](https://github.com/totec448-spec/chat-on-steroids/blob/v2.1.13/docs/skills.md).
