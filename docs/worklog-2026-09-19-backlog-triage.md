## Changes in this integration

- **Worker recovery (#314):** parked prime history no longer blocks a later ordinary turn from recovering its tab. Waking workers with undelivered messages can recover their exact absent chat. The asynchronous lookup rechecks the exact command, live run, unclaimed ownership, page absence, manual departure, Stop, recovery setting and bridge lifecycle before queuing the existing recovery owner.
- **Helper observations (#284):** a new page does not inherit elapsed warning time from a page that stopped reporting. A 90-second observation gap or backward clock starts a fresh 15-second grace; bounded state and previously announced health transitions remain intact.
- **Continuation diagnostics (#315):** marker outcomes are bounded and deduplicated. Rejection remains rejection and successful commitment is reported only after the continuation has settled. The wire contract and send authority are unchanged.
- **Slow observation delivery (#301):** both the initial journal batch and its 413 split retry wait up to 60 seconds for durable acceptance. The journal retains unacknowledged observations after timeout, and a later successful request drains them. Ordinary 10-second reads, the model route, journal concurrency and server request-body/header limits retain their existing owners.

Privacy, third-party notices, all 730 pinned native source checks and TypeScript passed. `npm run build` completed successfully. The final Extension suite contains 237 passing tests.

The fresh baseline feature checks also passed 84 tests for Spanish, Traditional Chinese, Skills, Project Files and Windows focus ownership. The Windows focus check compiles the actual C# method with substituted native boundaries; it is not a claim of live user-desktop acceptance. No macOS desktop runtime acceptance, installation or release publication was performed.

The first GitHub CI run for #316 passed Linux and macOS, including published-plugin checks, but exposed two Windows test-harness failures: an `ENOTEMPTY` teardown race in the output-budget MCP test and a 90-second timeout in the synthetic 5,001-session handoff catalog. The MCP harness now drains recorder publication and session/durable writes before resetting their owners and removing its directory. Both large catalog fixtures now clone a real persisted checkpoint, including its schema/watermark fields, and supply scoped synthetic file timestamps. The former public-summary fixture inadvertently triggered thousands of real legacy migrations. The catalog assertions still resolve the 5,001st entry and additionally reject filesystem artifacts from synthetic sessions. All three affected cases passed after these fixture corrections; no production timeout, scan cap or assertion was relaxed.
