# Changelog

Chat On Steroids is a beta. The app and companion extension share a version; reload the extension after updating the app.

## Unreleased

Changes on the current branch are described in their pull requests. Release notes are written when a version is prepared.

## [2.1.14] — 2026-09-17

- Added the optional desktop companion.
- Improved automatic continuation, queued input recovery, Stop handling and conversation ownership.
- Improved browser snapshots, tab release, project workspaces and worker overview.

[Full release notes](docs/release-notes/v2.1.14.md)
